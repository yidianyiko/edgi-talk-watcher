# 板端采集与局域网推理网关

2026-10-20。第一版板卡独立负责UVC采样、SDIO联网和屏幕；局域网网关负责已编译任务、Jev HTTPS请求和持久事件。模型密钥只留在网关，不编译或发送到板卡。UART屏幕代理和独立采图是互斥运行模式，启动器拒绝同时选择。

理由：当前板端官方UVC/WHD/lwIP驱动可构建，Jev现有接口需要JPEG和HTTPS；复用已验证网关可保持同一状态机和任务计划。板端上传320x240 YUYV，网关转换640x480 JPEG以满足模型最小边长。

代价：仍依赖常开的网关，不是板上模型推理或直接云端Jev客户端。当前LAN HTTP含图像和作用域令牌，部署仅用于预期可信局域网；普通网页和历史路由保持回环访问，只有带令牌的上传接口可从LAN访问。默认暂停，显式运行且受时限/次数限制，错误停止，无自动重试。

真实摄像头未接入板端、网络尚未关联，因此采集上传端到端硬件验收仍待资源条件满足；主机侧真实HTTP与真实Jev通路已单独验证，不冒充板端端到端成功。
