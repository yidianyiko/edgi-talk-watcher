# 看守屏幕角色

用户要求在板卡屏幕增加拟人角色，具体为两只眼睛。采用原生RGB565图形，不引入图片资源或新绘图库；保留现有任务、计数、状态、SPEAK及底部四操作区域。

眼睛居中在原大状态文字区域，状态文字移到其下方。待机圆眼、观察左右看、暂停眯眼、事件琥珀色睁大、不确定不对称、离线灰色；LISTENING睁大、RECOGNIZING左右思考。约4.8秒一次短眨眼。100ms既有循环仅在姿态变化时重绘，不新增线程、延时或改变业务状态。语音/看守状态仍由原协议驱动。

验收：绘图边界及状态/眨眼映射原生测试、原生渲染图检查、固件容量与链接检查、实板刷写校验和framebuffer读回。真实触摸和实体屏幕肉眼观感不能由framebuffer替代。刷写前保留当前V6，M33保持，最后恢复原服务到暂停状态。

实现与实板结果已归档至`../screen-face.md`；V7刷写校验、framebuffer读回、原生测试及独立review完成。实体触摸和实体屏幕照片未验证。
