# 事件语音提醒

用户已要求实现事件触发后的板卡扬声器通知，并限制同一事件重复提醒。

已选定首版：板卡内置固定中文“注意，看守任务已触发，请查看画面。”，无运行时TTS请求。电脑网页仍显示具体任务、时间和前后画面。沿现有电脑摄像头/统一WatchEngine/SQLite事件提交/UART状态桥传递一次性随机事件标识；仅新提交事件产生标识，持续event、历史恢复或删除不触发。每次播报同一标识只接受一次；心跳重发不重播。忙时可在桥侧重试，不阻塞相机/HTTP。

录音优先保持独占；扬声器至多等10秒获取音频所有权，播放期间新录音明确忙，播放后可再次录音。失败记录诊断，图片事件仍保存，不以串口ACK冒充实际发声。停止服务不重放旧事件。

固件仍限制在原M55四扇区，保持M33，烧录前保留V5并读回备份/校验。音频用8kHz G.711压缩，解码并复制采样为16kHz单声道PCM16，适配官方驱动。板载字库仍ASCII。

验收：HTTP新事件一次标识、链接保留/重启无旧提醒、固件去重/忙与解码参考向量、原有语音不回归；实板实际扬声器播放并用可用麦克风留档，自动识别或波形验证（明确证据能力），保存录像经真实服务触发并观测播报。没有可用录音设备时不宣称实体音频已验收。

实施状态：V6实板链路与录音恢复已通过；实体发声验收尚未通过，证据及边界以`docs/event-announcement.md`为准。忙时FIFO队列及匹配ACK避免后续事件覆盖未接受提醒，服务重启清空。
